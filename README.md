# FSportIN · Türne Fest

Quadro de jogos da equipa FSportIN no Re-Active Türne Fest ALL IN (Winter Edition), 28/11 a 08/12/2026, D'Ouro Padel.

- `index.html`: página (calendário embebido). Lê os resultados de `data.json`.
- `data.json`: resultados, actualizados de hora a hora a partir do padelteams.pt.
- `assets/`: logos FSportIN e Türne (versão branca) e ícone do lobo.
- `CNAME`: domínio `fsportin.ocd.pt` (GitHub Pages).

Mantido pela OCD Studio.
